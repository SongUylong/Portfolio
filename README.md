# 💼 Developer Portfolio Website

Personal software engineering portfolio showcasing projects, technical skills, and software background.

---

## ✨ Features

- 📱 **Fully Responsive:** Sleek, mobile-friendly interface designed with modern UI principles.
- 🎨 **Tailwind CSS & Animations:** Smooth transitions and interactive elements.
- 📂 **Project Showcase:** Detailed case studies, live links, and GitHub repository references.
- 📬 **Contact Form:** Direct communication channel for collaborations and opportunities.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router / React)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Deployment:** Vercel / Custom Cloudflare & Reverse Proxy

---

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/SongUylong/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the portfolio.
